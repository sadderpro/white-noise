# White Noise Generator

A simple web-based white noise generator built using the Web Audio API.

## Features

- Play / Pause white noise
- Seamless looping audio buffer
- Lightweight and minimal UI

## How it works

The app generates a short buffer of white noise (random samples between -1 and 1) and plays it in a loop using the Web Audio API.

## Usage

1. Open the project in a browser
2. Click the **Play** button
3. Click again to stop playback

## Status

Initial version: buffer-based white noise generation with play/pause control.
The project currently only contains a button and a slider, no styles, as it's currently in a very early stage.

Made as a learning project for audio programming and the Web Audio API.
